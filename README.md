# Adaptive AI Interview Coach

Real-time AI interview practice with adaptive difficulty, resume skill extraction, voice answers, and performance dashboard.

## Features

- **Live AI Questions** – generated by Groq LLM
- **Resume Upload** – PDF → skill extraction
- **Voice Answers** – record or upload audio → Groq Whisper transcription
- **AI Answer Evaluation** – Technical / Relevance / Completeness / Communication
- **Adaptive Difficulty** – gets harder or easier based on your score
- **Performance Dashboard** – charts, weak areas, recommendations, full history

## Setup

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Mac/Linux

pip install -r requirements.txt
streamlit run app/streamlit_app.py
```

Open http://localhost:8501

API key is already placed in `.env`.

## How to use

1. (Optional) Upload resume PDF → Extract Skills
2. Select Role, Level, Skill
3. Start Interview
4. Answer by typing **or** voice
5. Get instant AI feedback + next adaptive question
6. End interview → view full dashboard

## Project Structure

```
app/streamlit_app.py       → Main UI
src/
  llm_client.py            → Groq connection
  question_generator.py    → Live questions + bank fallback
  answer_evaluator.py      → AI scoring
  difficulty_manager.py    → Adaptive logic
  resume_parser.py         → PDF text extraction
  skill_extractor.py       → Skill detection
  speech_to_text.py        → Groq Whisper STT
data/question_bank.json    → Fallback questions
.env                       → GROQ_API_KEY
```
